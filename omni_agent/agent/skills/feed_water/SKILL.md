# 喂水技能
## 可用命令参考
| 命令                                    | 说明                              |
|---------------------------------------|---------------------------------|
| `turn -t user\table`                  | 机器人转身面向用户\餐桌方向                  |
| `pick cup`                            | 从桌上取起水杯（端起后默认处于高处）              |
| `lower-cup`                           | 将水杯从高处放低到用户嘴边高度                 |
| `deliver-cup -u <用户ID>`               | 将带吸管水杯递送到用户嘴边                   |
| `retract-cup`                         | 撤回水杯（回到高处）                      |
| `place cup`                           | 将水杯放回桌子                         |
| `observe_environment(duration=n)` | 使用摄像头拍摄照片（n=0）或录制视频（n>0，含音频），用于观察用户状态、动作和表情 |

> **注意**：`deliver-cup` 需要 `-u <用户ID>` 参数。用户ID 来自声纹识别结果；若护工或管理员指示服务某位老人，则使用该老人的ID。

## 操作流程
### 第一步：确认用户在场与状态
1. 用温和语气告知老人"我看下您的情况"，然后 `execute_shell("turn -t user")` 转身面向用户
2. `observe_environment()` 拍摄胸摄像头照片，画面已标注人脸检测结果（绿框=已注册用户，红框=未知人员），直接根据标注判断：
   - 画面中绿框标注了目标用户（框上名字与服务对象一致）→ 身份确认，继续下一步
   - 画面中无人或只有红框/陌生人 → 告知用户"请走到摄像头前面来"，重新执行本步
   - 目标用户不在画面中但检测到其他人 → 告知当前用户"请让<目标用户>到摄像头前来"，等待后重新执行
3. 身份确认后，观察照片中用户状态：
   - 坐姿端正、清醒 → 告知用户"我来喂您喝水"，进入第二步
   - 躺着/半躺/歪斜/睡觉/精神萎靡/表情痛苦 → 告知用户"您现在状态不适合喂水"，停止操作，通知护工
   - 不确定 → 主动询问"您感觉怎么样？想喝水吗？"，根据回答判断

### 第二步：取杯递送
1. `execute_shell("turn -t table")` 转向桌子
2. `execute_shell("pick cup")` 端起水杯（默认处于高处）
3. `execute_shell("turn -t user")` 转向用户
4. execute_shell("lower-cup")` 放低水杯到嘴边高度
5. 告知老人"我看看您准备好了没"，然后执行 `observe_environment(duration=3)`，观察用户喝水意图：
   - 用户**人离开、扭头、摆手或语音拒绝** → 跳转第四步
   - 其余情况默认用户想喝 → 继续下一步
6. 告知老人"来，慢点喝"，然后 `execute_shell("deliver-cup -u <用户ID>")` 递送水杯到用户嘴边
7. 递送完成后告知老人"我看看您喝得怎么样"，然后执行 `observe_environment(duration=6)`，确认用户是否开始喝水、姿势是否正常

### 第三步：等待喝够
根据观察结果进行判断：
   - 仍在正常喝水 → 告知老人"您慢慢喝"，继续执行 `observe_environment(duration=3)` 观察
   - 呛咳 / 扭头 / 推开 / 人离开画面 / 用户主动说喝够了 → 进入第四步收回
   - 连续观察两次仍不确定 → 主动询问用户"还喝吗？"，根据回答决定

### 第四步：收回水杯
1.  告知老人"我把水杯放回去"，然后`execute_shell("retract-cup")` 撤回水杯到高处
2.  `execute_shell("turn -t table")` 转向桌子
3.  `execute_shell("place cup")` 将水杯放回桌子
4.  `execute_shell("turn -t user")` 转向用户
5. 询问用户是否需要其他帮助

## 特别注意
- **必须先通过 `observe_environment()` 确认身份和状态**，身份不匹配或状态异常绝不喂水
- **执行 `execute_shell("lower-cup")` 和 `execute_shell("deliver-cup -u <用户ID>")` 后，必须立即调用 `observe_environment` 工具，观察用户状态，不可跳过。**
- 用户表示不想喝/喝够了/咳嗽等→ 立即进入收回流程
