# 喂饭技能
## 可用命令参考
| 命令                                      | 说明 |
|-----------------------------------------|------|
| `turn -t user\table`                    | 机器人转身面向用户\餐桌方向 |
| `pick bowl`                             | 从桌上端起碗勺 |
| `scoop`                                 | 用勺子舀一勺食物 |
| `deliver-spoon -u <用户ID>`               | 将舀好食物的勺子递送到用户嘴边 |
| `retract-spoon`                         | 撤回勺子 |
| `place bowl`                            | 将碗勺放回桌子 |
| `observe_environment(duration=n)` | 使用摄像头拍摄照片（n=0）或录制视频（n>0，含音频），用于观察用户状态、动作和表情 |

> **注意**：`deliver-spoon` 需要 `-u <用户ID>` 参数。用户ID 来自声纹识别结果；若护工或管理员指示服务某位老人，则使用该老人的ID。

## 操作流程

### 第一步：确认用户在场与状态
1. 用温和语气告知老人"我看下您的情况"，然后 `execute_shell("turn -t user")` 转身面向用户
2. `observe_environment()` 拍摄胸摄像头照片，画面已标注人脸检测结果（绿框=已注册用户，红框=未知人员），直接根据标注判断：
   - 画面中绿框标注了目标用户（框上名字与服务对象一致）→ 身份确认，继续下一步
   - 画面中无人或只有红框/陌生人 → 告知用户"请走到摄像头前面来"，重新执行本步
   - 目标用户不在画面中但检测到其他人 → 告知当前用户"请让<目标用户>到摄像头前来"，等待后重新执行
3. 身份确认后，观察照片中用户状态：
   - 坐姿端正、清醒 → 告知用户"我来喂您吃饭"，进入第二步
   - 躺着/半躺/歪斜/睡觉/精神萎靡/表情痛苦 → 告知用户"您现在状态不适合喂饭"，停止操作，通知护工
   - 不确定 → 主动询问"您感觉怎么样？想吃饭吗？"，根据回答判断

### 第二步：准备取餐
1. `execute_shell("turn -t table")` 转向桌子
2. `execute_shell("pick bowl")` 端起碗勺（默认处于高处）
3. `execute_shell("turn -t user")` 转向用户

### 第三步：喂一勺
1.  `execute_shell("scoop")` 舀一勺食物
2. 告知老人"我看看您准备好了没"，然后执行 `observe_environment(duration=3)`，观察用户进食意图：
   - 用户**人离开、扭头、摆手或语音拒绝** → 跳转第五步
   - 其余情况默认用户想吃 → 继续下一步
3. 告知老人"来，张嘴，慢点吃"，然后 `execute_shell("deliver-spoon -u <用户ID>")` 递送到用户嘴边
4. 递送完成后告知老人"我看看您吃得怎么样"，然后执行 `observe_environment(duration=6)`，确认用户是否开始咀嚼、姿势是否正常

### 第四步：等待吃够
1. `execute_shell("retract-spoon")` 撤回勺子到高处
2. 根据观察结果进行判断：
   - 正常咀嚼吞咽完毕 → 返回第三步再喂一勺
   - 呛咳 / 皱眉 / 扭头 / 推开 / 人离开画面 / 用户主动说吃饱了 → 进入第五步
   - 不确定 → 主动询问用户"还吃吗？"，根据回答决定

### 第五步：收拾餐具
1. 告知老人"我去收拾餐具"，然后 `execute_shell("retract-spoon")` 确保勺子已撤回
2.  `execute_shell("turn -t table")` 转向桌子
3.  `execute_shell("place bowl")` 将碗勺放回桌子
4.  `execute_shell("turn -t user")` 转向用户
5. 询问用户是否需要其他帮助

## 特别注意
- **必须先通过 `observe_environment()` 确认身份和状态**，身份不匹配或状态异常绝不喂饭
- **执行 `execute_shell("scoop")` 和 `execute_shell("deliver-spoon -u <用户ID>")` 后，必须立即调用 `observe_environment` 工具，观察用户状态，不可跳过。**
- 用户表示不想吃/吃饱了/咳嗽等 → 立即进入收拾流程
